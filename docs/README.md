# 拾光宣传网页

独立静态网页，源文件为 index.html；奶白与深绿风格，支持移动屏幕和键盘切换功能示意。所有示例数据为虚构，未使用私人记录。没有账号、追踪脚本或后端。

默认英文首页 index.html，中文版 zh.html。导航提供语言切换；App默认英文，可切换中文；网页两种语言与App功能保持一致。

在 docs 目录运行本地预览：python -m http.server 8767

结构与交互检查：node check.mjs

公开宣传可将本目录部署到静态托管，或在 GitHub 仓库 Settings → Pages 选择 main 分支的 /docs 目录。本次 Sites 发布因远端TLS握手失败未完成；不要将尚未发布的网址作为宣传链接。
