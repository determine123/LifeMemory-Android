Your memories. Your choices.

Your memories.
Your choices.

No account or self-hosted backend required. Choose local transcription or explicitly configure your own cloud provider.

Local-first

Audio, photos and records stay in the app’s private storage. Chinese OCR and offline transcription with an imported model run on your device.

Cloud processing is your choice

Cloud transcription uploads audio. AI recaps and chat send relevant text; image analysis sends the selected photo. A local failure never silently switches to cloud transcription.

Control retention and backups

Set an audio retention period and protect important recordings. Exported backups are unencrypted ZIP files; keep them safe. Backup import merges records and restores attachments while keeping existing entries.

Can I share moments with friends?

The Circle beta supports accounts, friend requests, text/photos, likes and comments. It requires a separately deployed HTTPS backend; no public Circle server is included. Only explicitly published content is uploaded. The private journal remains local. See the deployment guide.

Before your first day.

Before you begin.

How do I install it and get started?

Download the v0.8.0-alpha11 APK above and allow installation from your browser when Android prompts. This is a debug beta for Android 8.0+. Install over the existing version to retain your data. Import a Vosk Chinese or SenseVoice model for offline transcription; speaker separation needs an additional model bundle. Configure your own compatible AI provider for semantic recaps. Source and build instructions remain available on GitHub.

Does it identify speakers automatically or read health data?

Manual speaker correction is supported. Optional local sherpa-onnx speaker separation requires imported models; Auto can over-separate, so known speaker count can be set. Real-device accuracy still needs testing. Location, activity and mood are entered manually; there is no automatic heart-rate, stress or GPS collection.

Is uninterrupted all-day recording guaranteed?

Audio is saved in 1-, 3- or 5-minute segments. Manual sessions have a 12-hour cap; opt-in automatic mode continues until Stop or an OS interruption. Modern Android requires opening the app to resume after reboot. Battery use, background restrictions and gaps between segments still need real-device testing. Uninterrupted all-day recording is not guaranteed.

Is this a production release?

This is an MIT-licensed Android beta. Emulator tests cover offline transcription, manual speaker labels and data migration. Real-world noise and compatibility across device brands still need testing.
