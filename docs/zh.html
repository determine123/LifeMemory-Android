怎么安装和开始使用？

从 GitHub 获取源码，使用 Android Studio、JDK 17 和 Android SDK 35 构建 APK。安装后先导入 Vosk 中文模型，再开始离线转写；AI 总结需自行配置兼容接口。本页面暂不提供公开 APK 下载。

可以自动分辨每个人，或读取健康数据吗？

当前支持手动标注说话人，兼容云端返回的说话人字段；未验证自动多人分离。地点、活动和心情为手动记录，没有自动心率、压力或 GPS 采集。

是否能保证全天无间断录音？

采用 1 / 3 / 5 分钟分段保存，单次会话最长 12 小时。真机耗电、后台限制及分段间隙尚需验证，不承诺全天无间断。

这是正式产品吗？

这是 MIT 开源的安卓测试版。已有模拟器测试覆盖离线语音、手动说话人标注与旧数据迁移；真机噪声环境和多厂商兼容性仍需反馈。
